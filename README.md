# Landing Page

A modern, responsive landing page built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works seamlessly across all devices
- **Modern UI**: Clean and professional design with smooth animations
- **Easy to Customize**: Simple structure for quick customization
- **Smooth Scrolling**: Enhanced navigation experience
- **Contact Form**: Built-in form for user inquiries

## Structure

- `index.html` - Main HTML structure
- `style.css` - All styling and responsive design
- `script.js` - Interactive features and animations

## How to Use

Simply open `index.html` in a web browser to view the landing page.

To customize:
1. Edit the content in `index.html`
2. Modify colors and styles in `style.css` (see CSS variables at the top)
3. Update functionality in `script.js` as needed

## Sections

- **Hero**: Eye-catching introduction with call-to-action buttons
- **Features**: Showcase key features in a grid layout
- **About**: Information about your business or product
- **Contact**: Contact form for user inquiries
- **Footer**: Copyright and additional info

## Customization

You can easily customize the colors by modifying the CSS variables in `style.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --text-color: #1f2937;
    --light-gray: #f3f4f6;
    --dark-gray: #374151;
    --white: #ffffff;
}
```
