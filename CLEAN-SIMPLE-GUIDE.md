## 🚀 Quick Setup

### 1. HEAD HTML
- Open HubSpot page settings
- Go to **Advanced Options** → **HEAD HTML**
- Delete everything
- Paste from `hubspot-head-clean.html`
- Save

### 2. FOOTER HTML
- Same settings area
- Go to **FOOTER HTML**
- Delete everything
- Paste from `hubspot-footer-clean.html`
- Save

### 3. MODULE 1 (Hero)
- Find hero Rich Text module
- Click **Source Code** (< >)
- Delete everything
- Paste from `hubspot-module-1-clean.html`
- Exit source code mode
- Save

### 4. MODULE 2 (Product Selector)
- Find or create Rich Text module
- Click **Source Code** (< >)
- Delete everything
- Paste from `hubspot-module-2-clean.html`
- Exit source code mode
- Save

### 5. Replace Images
Replace placeholder images with your actual product photos in Module 2.

## 🐛 Troubleshooting

**Nothing works?**
- Make sure you pasted in SOURCE CODE mode
- Clear browser cache
- Check console for errors (F12)

**Product selector broken?**
- Verify FOOTER HTML is installed
- Check JSON data is valid
